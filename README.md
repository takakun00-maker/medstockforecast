# 八尾徳洲会総合病院 手術室 物品管理システム

手術に必要な物品の欠品・発注漏れをゼロにするための在庫管理システムです。

## システム構成

| ファイル | 機能 |
|---|---|
| `index.html` | トップページ |
| `medstock.html` | 需要予測ダッシュボード・ガントチャート |
| `medorder.html` | 発注チェックリスト・発注書生成 |

## アクセス

**アクセスにはパスワードが必要です（管理者にお問い合わせください）**

## 主な機能

- 実績13ファイル（118,540行）ベースの物品需要予測
- SPD在庫データとの自動照合
- 手術ガントチャート（1日/週/月ビュー）
- 発注チェックリスト（完了チェック・進捗管理）
- メーカー別発注書自動生成（印刷・CSV出力）
- 手術日別 必要物品×在庫確認

## 更新方法

毎朝SPD在庫ExcelとGT手術計画CSVをドロップするだけで全データが更新されます。
